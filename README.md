# MaSyMoS SEEK middleware (archived)

**This repository is kept for the record.** It is archived and not developed further.

This translator between SEEK and MaSyMoS 1.x is not part of MaSyMoS 2.0 and has no successor in
[MaSyMoS/masymos](https://github.com/MaSyMoS/masymos). It stays readable so that work which used
or cited it can still be followed.

The original README of this repository is preserved unchanged in
[README-legacy.md](README-legacy.md).
